# What you can write for every template

**Generated from the engine.** `node tools/copy-reference.js --write`
rebuilds this file by reading `system/js/cs-templates.js`, so it cannot
drift out of date. If a template learns a new word, this is where it
appears. Do not edit this file by hand — the next rebuild overwrites it.

Two columns, and the difference matters:

- **copy.js** — WORDS. They go inside the block named by the slide’s
  `copy:` key.
- **content.js** — SHAPE. How many, which drawing, which set. They go on
  the slide’s own line.

Write a word in the wrong file and nothing appears, with no error, because
the engine never looks for it there.

```js
// content.js — the slide’s line
{ template: 'context-2', copy: 'slide-03', media: 'slide-03_img-01' },

// copy.js — the block it names
'slide-03': {
  title: `The first heading`,
  body:  `The writing under it.`,
  title2: `The second heading`,
  body2: `The writing under that.`
}
```

---

## What a body can hold

Anywhere the table below says **a BODY**, you can write:

```js
body: `one paragraph`                       // a line
body: [`first`, `second`]                   // two paragraphs
body: [                                     // or any of these pieces,
  `a paragraph`,                            // mixed in any order
  { kind: 'points',    items: [`a`, `b`] },      // dashes — things settled
  { kind: 'questions', items: [`a`, `b`] },      // ? — things still open
  { kind: 'numbers',   items: [`a`, `b`] },      // 1. 2. — order matters
  { kind: 'heading',   text: `Part way down` },
  { kind: 'quote',     text: `A statement, set large` },
  { kind: 'drawer',    text: `Read more`, drawer: 'drawer-01' },
  { kind: 'image' }                              // a drawing, named from the slide
]
```

`cards: true` on a `points` / `questions` / `numbers` piece draws each line
as its own outlined card. `wide: true` spreads it across a full-width body.

---

## Three lists that are NOT in a slide’s block

These sit at the TOP LEVEL of copy.js, beside the slide blocks, and are
filed by **the drawing’s own name** rather than by slide:

```js
captions:  { ‘slide-04_img-01’: `the line under this drawing` },
questions: { ‘slide-04_img-01’: `the question it answers, above it` },
bodies:    { ‘slide-04_img-01’: `the writing beside it` }
```

They belong to the drawing, so they follow it as you step through a
carousel. `labels` is a fourth, filed by a tab’s or section’s id.

**A phase reads its own copy.js first**, and these four lists are the only
things that also come through from the study’s.
